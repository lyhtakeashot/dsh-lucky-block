# 冷知识内容库：来源、条目与黑名单

> 用途：为 DSH「幸运方块」插件提供**离线**冷知识数据。四季宝（Skippy）风格——犯罪统计、人体数据、意外死亡概率、略黑暗但真实。
> 数据文件建议落地为 `lib/trivia-data.json`（本次调研确认该文件此前不存在）。

## 一、可靠来源判定

调研期间本机直连网络受限（PowerShell/curl 的 DNS 与 TLS 大量失败，`en.wikipedia.org` / `zh.wikipedia.org` 均不可达）。实际可用的是 `web_fetch` 工具通道。经逐一实测，下列来源**可靠**且可访问，本次收录条目基本都溯源到它们：

| 来源 | 为什么算可靠 | 实测状态 |
|---|---|---|
| WHO Fact sheets（`who.int/news-room/fact-sheets`） | 联合国专门机构，每篇都有发布日期与一整套参考文献，数字可追溯 | 可访问，HTTP 200 |
| CDC（`cdc.gov`，含 WISQARS / NCHS / Yellow Book） | 美国联邦公共卫生机构，原始死因数据由法医/验尸官上报汇总 | 可访问，HTTP 200 |
| 各国统计机构（如 NHTSA、BLS、ONS、中国国家统计局） | 官方行政记录，方法论公开 | 部分可访问 |
| 世界卫生组织《World Health Statistics》/ Global Health Estimates | 全球疾病负担的统一口径估计 | 可访问 |
| Wikipedia「List of unusual deaths」类条目 | **仅作为线索来源**，必须回溯到其引用的原始报道才收录 | 主站不可达，改用镜像/引用 |

### 判定原则（本次执行）

1. **必须带数字或具名个案。** "很多人因此死亡"这类模糊表述一律不收。
2. **优先一手机构，其次百科。** 统计类只收 WHO/CDC/官方口径；史实类允许百科 + 交叉引用，但要求至少两处独立来源，否则降为 `medium`。
3. **时效性标注。** 死亡统计类条目均标明数据年份（如"2023 年"），避免读者误当最新值。
4. **宁可少收，不可错收。** 一条假冷知识在成品插件里的伤害远大于少十条真的。凡疑似网络讹传（无论多流行）一律不进正文，只进第四节黑名单。

### 置信度标记含义

- `high`：多来源权威一致，或单一机构但为官方一手统计/百科级史实。
- `medium`：单一可信来源，或存在口径差异（如不同年份、不同统计范围），数值取来源原文。

## 四、常见假冷知识（禁止收录 / 黑名单）

以下说法流传极广，但**经不起核实**或属于统计讹传。**禁止**进入冷知识库，且建议在插件层做关键词过滤：

| 假冷知识 | 为什么是假的 |
|---|---|
| 人类只用了大脑的 10% | 神经影像显示人几乎使用全部脑区，即使睡眠中也有活动。无任何科学来源支持"10%"。 |
| 金鱼的记忆只有 7 秒 | 实验证明金鱼记忆可达数月，能记住迷宫路线与声音信号。 |
| 长城是唯一能从太空用肉眼看到的人造物 | 多名宇航员明确否认；长城太窄，肉眼从近地轨道难以分辨。 |
| 人一辈子会吞下 8 只蜘蛛 | 1993 年一则杂志读者投稿的编造数据，作者本人已澄清是玩笑。 |
| 掉落椰子每年砸死约 150 人 | 广泛流传但**没有任何原始数据源**，常见于"鲨鱼更危险"类比文中。 |
| 自动售货机杀的人比鲨鱼还多 | 数字来源于一份无法追溯的旧年报，从未有官方统计支持。 |
| 人类和香蕉的 DNA 有 50% 相同 | 属对基因同源性的误读；比对的是部分保守基因，不是全基因组。 |
| 舌头有味觉分区图（酸甜苦咸各占一块） | 源自 1901 年一篇德文论文的翻译错误，现代味觉研究已否定。 |
| 剃毛会让毛发长得更粗更黑 | 只是新长出的断面视觉上更粗，毛发直径与颜色未变。 |
| 人死后指甲和头发会继续生长 | 是皮肤与软组织脱水收缩造成的视觉错觉，细胞早已停止分裂。 |
| 每天必须喝满 8 杯水 | 无科学依据；需水量因体重、气候、活动量差异极大，且食物也供水。 |
